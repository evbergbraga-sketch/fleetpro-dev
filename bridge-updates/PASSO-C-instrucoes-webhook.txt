(não é só colar código novo). Faça assim, com muito cuidado:

1) Abra o arquivo:
   nano /root/fleetpro-bridge/fleetpro-bridge-server.js

2) Use Ctrl+W para buscar por este texto exato:

   } else if (body?.numero || body?.lid) {

5) Logo ANTES dessa linha (ou seja, você vai colar 1 linha só,
   fechando o bloco "if" anterior e abrindo espaço para declarar a
   variável no branch seguinte). Adicione ANTES do "} else if":

   Vá até o final do PRIMEIRO bloco "if (body?.data?.key?.remoteJid) {"
